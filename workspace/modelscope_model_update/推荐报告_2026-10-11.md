## 新增 API 知识（已同步 browser_lessons sites/modelscope-cn.md）

1. 图片异步任务必须带 **`X-ModelScope-Async-Mode: true` 头**（GLM-Image 400 报错原文给出该文档）；Qwen/FLUX 系不带头也能拿 task_id，但任务会坏死
2. 视频生成端点为 `POST /v1/videos/generations`；报 `Invalid model provider` = 视频版"无 provider 绑定"（不可用判据，与 chat 的 `has no provider supported` 等价）
3. `submit failed with code: 40212` = 图片任务提交被拒（GLM-Image / PE 系，具体语义待考）
4. "提交 200 + task_id 但任务秒 FAILED task not found" = 免费层无推理绑定的新形态（模型页存在、提交通路存在、实际不可用）——**下轮可用本报告脚本 `temp/ms_scan/verify3.py` 一键复查这 5 个 image 模型是否恢复**
